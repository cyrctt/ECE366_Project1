# ECE366 Project 1

This repository contains Verilog implementations and simulations of several digital adder and subtractor architectures. The project focuses on comparing different circuit designs and understanding how logic-level trade-offs affect performance, complexity, and implementation style.

## Included designs

- 1-bit adder/subtractor
- 4-bit ripple-carry adder/subtractor
- 32-bit carry-lookahead adder
- 16-bit parallel-prefix adder

These designs are implemented in Verilog and are intended to be tested using simulation testbenches.

## Project goals

- Explore fundamental arithmetic circuit design in Verilog
- Implement multiple adder architectures
- Compare ripple-carry, carry-lookahead, and parallel-prefix approaches
- Validate logic behavior using simulation-based testing

## Simulation

The designs are intended to be tested with Verilog testbenches and can be simulated in tools such as EDA Playground or a local Verilog simulator.
